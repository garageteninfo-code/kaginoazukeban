利用条件・個人情報の扱い

鍵の預け番（もしもの時のメモを、何人かに分けて預ける紙のカード／無料・試作版）。

1. この道具がすること

あなたが書いたメモに鍵をかけ、その鍵を何枚かのカードに分けます（Shamir の秘密分散と、ブラウザの標準の暗号 AES-GCM）。決めた枚数のカードがそろった時だけ、メモが読めます。鍵をかける・分ける・開けるは、あなたのブラウザの中だけで行います。

2. 集めない・送らない

  • メモ、会社・お店の名前、預け先の呼び名、カードの文字、封筒の文字、記録を、提供者を含むどこにも送りません。この画面には、インターネットへ送る仕組みが入っておらず、送ることを禁じる設定（CSP）もしています。
  • この画面は、メモやカードをブラウザに残しません（localStorage などに書きません）。画面を閉じると消えます。「印刷」「保存」のボタンを押したときだけ、あなたのブラウザが、あなたのプリンターやパソコンに出します。
  • 提供者は、メモもカードも控えも持っていません。カードや封筒をなくしたとき、提供者が代わりに開けることはできません。
  • この画面は GitHub Pages（GitHub, Inc. の無料の置き場所）から配っています。GitHub は、画面を開いた人の接続の記録（IP アドレスなど）を、安全のために残すことがあります。詳しくは GitHub の個人情報の扱いをご覧ください。提供者は、その記録を見たり使ったりしません。

3. 保証しないこと

  • この道具は、暗号の専門家の点検を受けていません。乱数と暗号はブラウザの標準の仕組みを使っています。
  • 決めた枚数のカードを集めた人は、メモを読めます。カードの紙そのものは守れません。1枚ずつ別の人・別の場所に預けてください。決めた枚数がそろわなくなると、メモは誰にも読めなくなります。
  • 印刷の見た目は、プリンターと紙では確かめていません。作ったら、試しに開けられるかを必ず確かめてください。
  • 記録の書き換えに気づける仕組みは、最後の行を消したこと、カードに印刷した「記録の印」より後ろを全部作り直したことは見分けられません。
  • この道具を使ったこと、または使えなかったことで利用者に生じた損害について、提供者が賠償の責任を負う場合の額は、1万円を上限とします。
  • この上限は、提供者の軽い過失（重大な過失にあたらない過失）による損害の場合に限って当てはめます。提供者に故意または重大な過失がある場合は、上限を当てはめません。
  • 利用者の国や地域の法律で、ここに書いた上限よりも利用者に有利な決まりがある場合は、その決まりが優先します。
  • 銀行のネットバンキングなどのパスワードを人に知らせてよいかは、その銀行・サービスの決まり（規約）に従ってください。他の人に知らせると補償の対象外になる例があります。
  • このメモは、法律上の遺言や契約の書類にはなりません。法律の判断はしません。
