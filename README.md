# 鍵の預け番（試作）

社長しか知らない「金庫の番号」「パスワード管理アプリの親パスワード」などを、何人かに分けて預ける紙のカードを作る道具です。決めた人数（たとえば 3 人のうち 2 人）がそろった時だけ、もしもの時のメモが読めます。1 枚だけでは何も分かりません。

- ページ：https://garageteninfo-code.github.io/kaginoazukeban/
- **無料**です。登録もいりません。
- できること：① 作る（メモに鍵をかけ、2〜9 枚のカードと封筒を作って印刷・保存）／② 点検する（カード 1 枚が読めるか）／③ 開ける（そろったカードで読む）／④ 記録を確かめる（点検・開けた記録の書き換えに気づく）。
- 仕組み：Shamir の秘密分散と、ブラウザの標準の暗号（AES-GCM）。カードの文字には書き違いを見つける検査が付いています。

## データはブラウザの外に出ません
鍵をかける・分ける・開けるは、すべてあなたのブラウザの中だけで行います。このページには、インターネットへ送る仕組みを入れていません。送ることを禁じる設定（CSP：`connect-src 'none'` など）もしています。メモはブラウザにも残しません。提供者は、メモもカードも持っていないので、なくしたときに代わりに開けることはできません。
ただし、ページを配っている GitHub Pages は、ページを開いた人の接続の記録（IP アドレスなど）を残すことがあります。

## 正直な限界
- 試作版です。暗号の専門家の点検は受けていません。
- 決めた枚数のカードを集めた人は、メモを読めます。カードは 1 枚ずつ別の人・別の場所に預けてください。
- 印刷の見た目は、プリンターと紙では確かめていません。作ったら、試しに開けられるかを確かめてください。
- メモが長いと、封筒の行が増えます（約 200 文字で 51 行）。メモは「置き場所と開け方」だけ短く書くのがおすすめです。QR コードはありません。
- 記録は、最後の行を消したことと、カードの「記録の印」より後ろを全部作り直したことは見分けられません。
- このメモは遺言や契約の書類にはなりません。銀行のパスワードを人に知らせてよいかは、その銀行の規約に従ってください。
- 画面は日本語だけです。
